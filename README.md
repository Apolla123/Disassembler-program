# Как запустить код на своём компьютере:
- Установите Python 3.8+
- Установи библиотеки: pip install -r requirements.txt
- Запустите сервер (надо написать в терминале): uvicorn main:app --reload
- Откройте в браузере: http://127.0.0.1:8000
(Если сайт не показывается, значит проблема с портом, попробуйте написать: uvicorn main:app --reload --port 8002, тогда ссылка будет: http://127.0.0.1:8002)
